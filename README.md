# Evaluación 2

## Descripción
Este repositorio contiene los programas desarrollados para la Evaluación 2, utilizando Python, Postman y servicios API.

## Actividad 1: API de biblioteca
Pruebas de consulta, creación y actualización de libros mediante la API de biblioteca.

## Actividad 2: Generación de libros aleatorios
Script `Ramdom50libros.py` para generar y consultar libros mediante Python.

## Actividad 3: Geolocalización
Script `Graphhopper.py` para consultar ubicaciones, calcular rutas y mostrar instrucciones de recorrido.

## Tecnologías utilizadas
- Python 3
- Git y GitHub
- Postman
- API de biblioteca
- GraphHopper API
